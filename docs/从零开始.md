> 这份文档写给**从没装过 BetterGI** 的人。跟着做完，你会得到：一个能自己跑原神日常的 BetterGI，和一个能用一句话使唤它的 AI 桌宠（Coopanion）。

> 全程不需要写代码、不需要命令行基础。大约 30 分钟，其中一半时间在等下载。

## 1. 先搞清楚三个东西是什么关系

| 角色 | 是什么 | 干什么 |
|---|---|---|
| **BetterGI**（更好的原神） | 一个开源的**原神自动化工具**，靠图像识别 + 模拟键鼠工作 | 真正去捡东西、打本、跑日常、刷圣遗物 |
| **Coopanion** | 一个**AI 桌宠**（基于 Cortico 框架），桌面上那只可以聊天的小家伙 | 理解你说的话，决定「现在该干什么」 |
| **本插件**（cortico-world-bettergi） | 给 Coopanion 加的一个**扩展** | 把「跑日常」翻译成 BetterGI 认识的命令行，发过去；再把它跑没跑起来如实报回来 |

一句话：**BetterGI 是手，Coopanion 是脑子，本插件是神经。**

所以顺序不能反：**先让 BetterGI 自己会干活，再让桌宠指挥它。** 很多人失败就失败在跳过了第二步——BetterGI 自己都没调通，插件发再多命令也是空转。

## 2. 动手前先自查

| 条件 | 要求 | 不满足会怎样 |
|---|---|---|
| 操作系统 | **Windows 10 或更高，64 位** | BetterGI 不支持手机、不支持 Linux/macOS |
| 运行库 | **.NET 8 运行时**（桌面版 x64） | 双击没反应，或提示 `You must install or update .NET` |
| 权限 | 能点 UAC「是」，或能以管理员身份运行程序 | 模拟点击全失效，日志会写「模拟键鼠消息发送失败」 |
| 硬件 | 至少能中画质 60 帧跑原神 | 图像识别吃性能，低配机器部分功能会很难用 |
| 游戏 | 原神 PC 端（含云原神也可） | — |
| 账号 | 你自己承担使用风险（见[第 11 节](#11-原理与边界)） | — |

官方原话（[快速上手](https://www.bettergi.com/quickstart.html)）：

> Windows 10 或更高版本的 64 位系统；.NET 8 运行时（没有的话，启动程序，系统会提示下载安装）
> 推荐的电脑配置至少能够中画质 60 帧流畅游玩原神，否则部分功能的使用体验会较差。

## 3. 第一步：安装 BetterGI

### 3.1 下载

官方渠道（任选其一，别去第三方站）：

- GitHub Releases：<https://github.com/babalae/better-genshin-impact/releases>
- 官方下载页（含加速镜像与网盘）：<https://www.bettergi.com/download.html>

GitHub 慢的话，官方在下载页给了几个公益加速站，比如 `https://github.akams.cn/`——把 GitHub 链接粘进去即可。

### 3.2 选哪个文件

| 文件名 | 类型 | 适合谁 |
|---|---|---|
| `BetterGI.Install.版本号.exe` | 安装版（离线） | **推荐**，装完自动更新，开始菜单有快捷方式 |
| `BetterGI.OnlineInst.exe` | 安装版（在线） | 想边下边装 |
| `BetterGI_v版本号.7z` | 便携版 | 不想写注册表、想放 U 盘带走的人；解压即用 |

**版本号挑更高的。** 本插件用 **0.66.0** 完整验证过；`一条龙` 指定配置名的功能需要 **0.45.3 及以上**。

### 3.3 安装

1. 双击安装包，一路下一步。**装到全英文、无空格的路径最省事**（默认的 `C:\Program Files\BetterGI` 就很好）。
2. 如果 Windows 弹出「无法验证发布者」或 SmartScreen 蓝色提示：点「更多信息」→「仍要运行」。这是未签名开源软件的常态。
3. 如果杀毒软件（含 Windows Defender）报毒或静默拦截：把 BetterGI 的安装目录**加入白名单**。官方 FAQ 明确说过，模拟操作被拦截是杀软造成的。

### 3.4 首次启动

1. 双击桌面快捷方式（便携版则双击目录里的 `BetterGI.exe`）。
2. **会弹 UAC，必须点「是」。** 官方原话：*如果没有弹 UAC 提示，请手动右键，并选择「以管理员身份运行」！*
3. 如果提示缺 .NET，按提示装 [.NET 8 运行时（桌面版 x64）](https://dotnet.microsoft.com/zh-cn/download/dotnet/thank-you/runtime-desktop-8.0.16-windows-x64-installer)，装完重新启动。

✅ **检查点**：BetterGI 主界面出现，没有报错弹窗。

## 4. 第二步：让 BetterGI 自己能跑通

这一步**不可以跳过**。插件只负责「发命令」，命令能不能落地全靠这里。

### 4.1 先把游戏设置调对

启动原神，进游戏设置，确认这五条（全部来自官方快速上手）：

- [ ] **游戏语言 = 简体中文**（不支持其他语言）
- [ ] **分辨率 1920×1080**（16:9；全屏或窗口都行，低于 1600×900 的部分功能会出问题）
- [ ] **亮度保持默认**
- [ ] **关闭一切画面滤镜**（HDR、N 卡滤镜、ReShade 等）
- [ ] **DirectX 层没有遮挡元素**（比如 MSI Afterburner 的帧数显示，会挡住识别要素）

### 4.2 启动并确认

1. 回到 BetterGI，在「**启动**」页选好**截图方式**（默认 BitBlt 兼容性最好；**用云原神必须选 WindowsGraphicsCapture**）。
2. 点「**启动**」。BetterGI 会激活原神窗口。
3. 等窗口左下角的**日志开始滚动**，说明识别已经在工作。

> 如果你用云原神、或者电脑里有多个原神、或者要通过别的启动器开游戏，把「**同时启动原神**」关掉。

### 4.3 自测：自动拾取

官方推荐的自测方法，**先测这个再谈其他功能**：

1. 在「实时任务」页确认「自动拾取」是开着的（默认开）。
2. 去游戏里随便找个采集物或掉落物，站到旁边。
3. 看它会不会自己按 F 捡起来。

不对的话按这个顺序查：

| 现象 | 原因 | 处理 |
|---|---|---|
| 左下角日志里没有「交互或拾取」 | 截图没抓到画面 | 换「截图方式」逐个试；确认没有滤镜遮挡 |
| 有日志但人物不动 | 模拟点击被拦 | 确认是**管理员权限**运行；把 BetterGI 加杀软白名单 |
| 日志写「模拟键鼠消息发送失败」 | 被安全软件拦截 | 关闭杀软或加白名单 |

✅ **检查点**：站到掉落物旁边，它会自己捡。**到这一步才算 BetterGI 装好了。**

## 5. 第三步：在 BetterGI 里准备好「可被调用的东西」

插件能触发的只有两种东西，你得先在 BetterGI 界面里把它们建出来。

### 5.1 调度器配置组（推荐）

「配置组」= 一串按顺序执行的任务（跑地图路线、脚本、键鼠录制等）。

1. 打开 BetterGI →「**全自动**」→「**调度器**」。
2. 新建一个配置组，起个**好记的中文名**，比如 `日常`、`挖矿`。
3. 往里加任务，保存。

它保存成 `你的BetterGI目录\User\ScriptGroup\<名字>.json`——**文件名就是组名，插件就是按这个名字找的。**

> 别忘了先在「快捷键」里给「停止当前脚本任务」绑一个键，否则跑起来停不下来。

### 5.2 一条龙配置

1. 打开「**一条龙**」页，把要跑的流程勾好，保存。
2. 保存后会出现在 `你的BetterGI目录\User\OneDragon\<名字>.json`——同样，**文件名就是配置名**。

✅ **检查点**：打开 `User\ScriptGroup` 和 `User\OneDragon` 两个目录，能看到你起的名字。**记下这两个名字，后面要用。**

## 7. 第五步：安装本插件

### 7.1 从扩展市场装（推荐，等它上架后）

Coopanion → 设置 → **高级模式** → **扩展** → **扩展市场** → 搜 `bettergi` → 安装 → **重启进程**。

> 「重启进程」是必须的：只重启某个 World 不够，新装的扩展要整进程重启才会加载。

### 7.2 从本机目录装（开发者方式）

1. 把仓库克隆/下载到本地，在包目录里装依赖：

   ```bash
   corepack pnpm install
   ```

2. Coopanion → 高级模式 → 扩展 → **手动安装** → 选本机目录，填这个包的**绝对路径**（link 方式装入）。
3. 重启进程。

### 7.3 填两个路径

到「**World 总览**」找到 `BetterGI`，启用它，并确认配置：

| 配置项 | 填什么 | 说明 |
|---|---|---|
| `exePath` | `BetterGI.exe` 的绝对路径 | 安装版默认 `C:\Program Files\BetterGI\BetterGI.exe`；**便携版要改成你解压的位置** |
| `userDir` | 留空 | 留空 = `<exe 所在目录>\User`，一般不用动 |
| `launchTimeoutMs` | 默认 20000 | 机器慢就调大 |
| `allowStop` | 默认开 | 关掉后插件不能结束 BetterGI 进程 |
| `stopGraceMs` | 默认 5000 | 先请它自己关，等不到才强杀 |

> **强烈建议把 Coopanion 也设成「以管理员身份运行」**（右键快捷方式 → 属性 → 兼容性 → 以管理员身份运行此程序）。否则插件每次启动 BetterGI 都会弹一次 UAC 等你点，无人值守时等于失败。

## 8. 第六步：验收（四步验证法）

按顺序对桌宠说这四句话，一层层排除问题。

**① 「BetterGI 在跑吗？原神开了没？」**

它应该回：进程在不在、**当前有没有提权**、`exePath` 对不对、读到几个配置组、游戏在不在跑。

- 如果回「exePath 不存在」→ 回去改 `exePath`（便携版最常见）。
- 如果回「当前进程未提权」→ 按 7.3 结尾那条把 Coopanion 设成管理员运行。

**② 「能跑哪些配置组？」**

它应该把你建的名字念出来（比如 `日常、挖矿`）。

- 念不出来 → 说明 `userDir` 指错了，或者你还没在 BetterGI 里建过配置组（回第 5 节）。

**③ 「先别真跑，看看你会发什么命令」**

这是**演算模式**（`dryRun`），只会回显一行命令，不会启动任何东西。确认命令长这样：

```
"C:\Program Files\BetterGI\BetterGI.exe" --startGroups 日常 挖矿
```

名字、顺序、路径都对，再往下走。

**④ 「好，现在真跑日常」**

它会先看 BetterGI 是否已在运行：

- 没在跑 → 直接启动（未提权的 Coopanion 会弹 UAC，点「是」）。
- 已在跑 → 见[第 10 节](#10-出问题了看这里)「已经在运行了怎么办」。

✅ **检查点**：BetterGI 窗口起来，游戏里开始动。

## 9. 日常怎么用

不用记工具名，会说话就行：

| 你说 | 它做 |
|---|---|
| 「帮我把原神日常跑一下」 | 先查有哪些配置组，再按你给的顺序发出去 |
| 「先跑挖矿，再跑日常」 | `groups: ["挖矿", "日常"]`，按顺序执行 |
| 「用默认配置跑一条龙」 | `oneDragon` + 配置名 |
| 「原神今天还挂在那吗」 | 查进程 + 游戏进程 |
| 「先别跑，把命令给我看看」 | 演算模式，只回显命令 |
| 「关掉 BetterGI」 | 优雅关闭，超时才强杀 |

三条使用纪律：

1. **一次说清要跑哪几组**，别让它猜。
2. **第一次跑新配置组，先用演算模式确认命令**。
3. **它在游戏里真的会动**（消耗体力、动背包、上下线），别在你在打深渊的时候让它开日常。

## 10. 出问题了看这里

### 插件侧

| 现象 | 原因 | 处理 |
|---|---|---|
| 回「exePath 不存在」 | 路径错，或装了便携版还用着默认路径 | 改成你真实的 `BetterGI.exe` 路径 |
| 回「这些配置组不存在」并列出名字 | 组名打错/大小写不对/还没建 | 照它列出的名字重说一遍；名字 = `User\ScriptGroup` 下的文件名 |
| 回「已在运行，而这条指令没有 URL 协议」 | BetterGI 是单实例；`--startGroups` 和带配置名的一条龙**没有**协议版本（官方明说） | 让它先关再启（`restartIfRunning`），或先叫它关掉再重发 |
| 回「命令发出去了，但没看到进程起来」 | UAC 弹窗被点「否」或被系统策略拦了 | 看托盘有没有 UAC 窗口；或把 Coopanion 设为管理员运行 |
| 回「当前进程未提权」 | Coopanion 不是管理员 | 设成管理员运行；否则每次都要点 UAC |
| 「配置组有了，但游戏里没反应」 | BetterGI 自己在空转 | **回第 4 节自测自动拾取**，那是根因所在 |
| 装扩展时报 `ERR_PNPM_EPERM` | 同时有两个 pnpm 在动同一个目录（比如你连着点两次安装） | 一次只点一次；关掉扩展页再重试 |

### BetterGI 侧

| 现象 | 原因 | 处理 |
|---|---|---|
| 双击没反应 / 提示装 .NET | 缺 .NET 8 运行时 | 装桌面版 x64 运行时 |
| 日志不动 | 截图方式不对 / 有滤镜遮挡 | 换截图方式；关滤镜；关帧数覆盖层 |
| 日志有、人不动 | 没有管理员权限，或杀软拦截 | 右键以管理员运行；加白名单 |
| 找不到 `User` 目录 | 便携版在你解压的目录里 | 路径是 `<解压目录>\User` |
| 任务跑一半卡住 | 分辨率/亮度/滤镜变了，或游戏更新动了 UI | 回到第 4.1 重新核对五条设置 |

### 日志在哪

- BetterGI 自带日志窗口（左下角），最直接。
- 需要的文件日志一般在 BetterGI 目录下的 `log\` 目录。
- 报 issue 时请附：BetterGI 版本、Coopanion 版本、插件版本、截图、以及「是连不上 / 是命令没生效 / 还是游戏里没反应」——这句话能省掉一半来回。

## 11. 原理与边界

**它做了什么**：把你的话翻译成 BetterGI 的命令行参数，启动进程或把指令交给已在运行的实例，然后把「进程起没起来、退出码、原始输出」如实报回来。

**它没做什么**：

- 不读游戏内存、不改游戏文件、不注入进程、不模拟键鼠——那些是 BetterGI 干的事。
- **看不见任务进度**。BetterGI 没有查询接口，跑到哪、有没有卡住，只能看它的界面日志。插件只会说「命令发出去了、进程起来了」，不会说「日常跑完了」。
- **不能逐项开关功能**。命令行只覆盖 `start`、`oneDragon`、`--startGroups` 三种动作，没有「只开自动拾取」这种参数。

**关于封号**：BetterGI 官方在 README 与 FAQ 里的说法是「理论上不会被封，因为不做修改游戏文件、读写内存这类行为」，但同时也说明**用户条款把第三方软件/模拟操作列为封号理由之一**，请低调使用。本插件不改变这个风险，也不做任何安全承诺——**用不用、怎么用，你自己决定并承担后果**。

**关于权限**：BetterGI 必须以管理员运行才能模拟键鼠。插件启动它时会走 UAC；你把 Coopanion 也设成管理员，就能免掉每次弹窗。

---

## 12. 卸载与回滚

1. Coopanion → World 总览 → 停用 `BetterGI`（或直接卸载这个扩展）→ 重启进程。
2. BetterGI 本身不动也能继续用——它只是个独立软件，卸载插件不影响它。
3. 想彻底清干净：删掉扩展目录里对应的包，重启进程。
